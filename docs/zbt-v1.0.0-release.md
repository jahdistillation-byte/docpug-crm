# Doc.PUG CRM ZBT v1.0.0

Первая стабильная сборка для сопровождаемого закрытого тестирования с
1–3 клиниками.

## Подтверждённый сценарий

`клиника → подписка → владелец → пациент → запись → приём → услуги → склад →
стационар → выписка → завершение → оплата → журнал → Telegram`

## Включено в релиз

- изоляция данных клиник в проверенном пользовательском сценарии;
- создание клиник платформенным администратором;
- ручное управление периодом доступа;
- журнал действий владельца;
- ежедневный отчёт владельца и отправка в Telegram;
- защита Telegram-отчётов от повторной отправки;
- корректное состояние загрузки пациентов;
- темы, брендинг и предпросмотр документов.

## Проверки релиза

- синтаксис `server.py` и `app.js`;
- целевые тесты Telegram-доставки;
- тест повторных запросов списка пациентов;
- ручной сквозной тест в отдельной клинике ZBTS;
- ручная проверка отсутствия пересечений в журнале и Telegram.

## Известные ограничения ЗБТ

- подключение и продление клиник выполняется вручную;
- автоматической оплаты подписки пока нет;
- запуск рассчитан на небольшое число клиник с ручным сопровождением;
- общий исторический набор тестов содержит устаревшие проверки финансовых и
  защитных сценариев и должен быть приведён в соответствие отдельно.

## Восстановление

Git-тег `zbt-v1.0.0` обозначает зафиксированную версию исходников и миграций.
Перед откатом базы необходимо отдельно оценить совместимость данных: Git-тег
сам по себе не отменяет уже применённые миграции Supabase.
