# Счёт стационара в документах пациента

7 ноября 2026. Изменений схемы базы нет.

## Поведение

- В «Документи» добавлен «Рахунок стаціонару», доступны текущие и завершённые
  госпитализации пациента. Медицинская выписка по-прежнему выбирается только
  для завершённых госпитализаций. Сводка источников учитывает все госпитализации.
- Во вкладке «Рахунок» карты стационара добавлена кнопка «Сформувати PDF».
- Оба входа используют один downloadHospitalBillPdf: читают госпитализацию
  и get_hospital_billing_state через существующие API текущей организации.
  Пациент проверяется по id, состояние организации — до и после чтения.
- PDF содержит клинику, пациента, владельца, период госпитализации,
  фактически начисленные услуги/материалы, количества, единицы, цены, суммы,
  итог и дату формирования. Это документ начислений, без отметки об оплате.
- Суммы проверяются точной арифметикой, общий итог должен совпадать с суммой
  сохранённых строк. Названия и данные пациента экранируются и не переводятся
  как служебные подписи. PDF использует общий A4-рендерер и стиль документов.
- Для счёта включены номер страницы и ссылка на госпитализацию внизу страницы.
  Генератор защищён от одновременного экспорта двух документов.
- Ошибка загрузки госпитализаций не выдаётся за отсутствие данных; есть повтор.
  Документы не создают новые начисления, складские движения или оплаты.

Документ доступен как источник в CRM; PDF формируется из текущих сохранённых
начислений на момент запроса и скачивается пользователю. Отдельный архив версий
PDF или загрузка файла в хранилище этим изменением не добавляются.

## Проверено

Браузерные сценарии с настоящими функциями документов и имитацией только API:
текущая и завершённая госпитализации, выбор источника, настоящий экспорт jsPDF +
html2canvas, суммы 101,45 и 2029,00 UAH, 40 строк на трёх страницах A4,
экранирование и сохранение оригинальных названий/имени, английские подписи,
проверка пациента, несовпадение итогов, отказ API, повтор загрузки и ширины
768/390/320. Полученные PDF преобразованы Poppler в изображения и просмотрены.
Проверки синтаксиса и выдачи статических файлов пройдены. Существующий браузерный
сценарий назначений/списания/счёта также проходит. Живые данные не изменялись.
